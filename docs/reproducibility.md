# Numerical Study Reproducibility

This note records the files needed to reproduce the numerical study and the
upload-ready Statistica Sinica package.

## Environment

Install the Python dependencies from the repository root:

```powershell
python -m pip install -r requirements.txt
```

The code was run with Python 3.13 on Windows. Python 3.10 or newer is expected
to work. Full simulations are CPU-heavy; use reduced `--reps` values for smoke
checks.

## Data

The real-data application uses:

```text
data/pbcseq.csv
```

This is the Mayo PBC longitudinal dataset corresponding to R
`survival::pbcseq`.

## Full Numerical Pipeline

The complete pipeline can be run from the repository root with:

```powershell
python simulations\part1_vcm.py --reps 1000 --workers 6
python simulations\part2_joint.py --reps 1000 --workers 6
python simulations\part2_bonferroni.py --reps 1000 --workers 8
python simulations\part3_mean.py --reps 1000 --workers 6

python realdata\pbc_data_illustration.py
python realdata\pbc_mean.py
python realdata\pbc_vcm.py

python simulations\gen_plot_curves.py
python simulations\plot_bands.py
python simulations\build_excel.py
```

For convenience, the same commands are collected in:

```text
scripts/run_numerical_pipeline.ps1
```

Part 2 was also run with:

```text
scripts/run_part2_full.ps1
```

The Part 2 full run covers 18 cells:

```text
n in {200, 300}
m in {5, 10, 15}
noise in {gauss, uniform, laplace}
```

## Tracked Outputs

The numerical results used in the write-up are committed under:

```text
results/part1/part1_summary.csv
results/part2/part2_summary.csv
results/part2_bonferroni/part2_bonferroni_summary.csv
results/part3/part3_summary.csv
results/simulation_results.xlsx
results/figures/
results/realdata/
```

Per-replicate JSON files are intentionally not tracked because they are bulky
and are regenerated by the simulation scripts. The committed summary CSV files
are the manuscript tables' numerical source.

## Manuscript And Upload Package

The working numerical-study source is:

```text
docs/numerical_study_ss.tex
docs/references.bib
```

The upload-ready Statistica Sinica package is:

```text
upload_numerical_study_ss/
upload_numerical_study_ss.zip
```

The upload package contains `SS-template.tex`, `SS-template.pdf`, `references.bib`,
`SS-template.bbl`, `chicago.bst`, and all local figures referenced by the TeX
file. Compile inside that directory with:

```powershell
pdflatex SS-template.tex
bibtex SS-template
pdflatex SS-template.tex
pdflatex SS-template.tex
```

## Validation

The following checks were run before upload:

```powershell
pytest tests/ -q
pdflatex -interaction=nonstopmode SS-template.tex
```

The LaTeX build completes successfully. The SS template emits non-fatal
`fancyhdr` headheight warnings and one small float-height warning.
